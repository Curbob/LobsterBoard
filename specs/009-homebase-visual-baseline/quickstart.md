# Homebase Visual Baseline Quickstart

Run the Homebase QA gate first so fresh screenshots exist:

```bash
npm run check:homebase
```

Then run the visual baseline directly:

```bash
npm run homebase:visual-baseline
```

Expected output:

```text
Homebase visual baseline: ok
phone:465/700, ipad:1161/1300, desktop:1161/1300
```
